## 🚀 Highlights

The `Tutorial_1_3_Industry_Ready...` folder has the most polished work — each program takes structured input, validates it, and prints a formatted summary. Good examples if you want to see what I can build with plain Java (no frameworks):

- **FlightBooking.java** — fare calculation with age-based discounts and excess luggage penalty
- **PosSystem.java** — point-of-sale billing
- **LoanEligibility.java** — eligibility check based on income/criteria
- **WarehouseInventory.java** — inventory tracking logic

## 🛠 How to run any program

```bash
javac FileName.java
java FileName
```

Some programs take command-line arguments — check the comment at the top of the file for usage.

## 📌 Notes

This is a learning log, not a polished library — code quality and style improve as you move through the folders in date order. Compiled `.class` files are excluded via `.gitignore`; only source is tracked.
